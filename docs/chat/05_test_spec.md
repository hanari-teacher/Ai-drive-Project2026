# リアルタイムチャット機能 テスト仕様書 (`docs/chat/05_test_spec.md`)

---

## 1. テスト方針・前提条件

- **対象機能**: `/chat` チャット画面、`/api/chat/*`、デフォルトルーム（`default`）の `Socket.IO` 配信および DB 同期／ポーリング併用、セッション単位の定員管理（最大5名、同一ブラウザ複数タブは1名カウント）、入力検証、例外・XSS対策、既存機能回帰。
- **前提**:
  - 検証用 Neon（PostgreSQL）に `chat_messages` およびセッション参加管理テーブル／共有状態が適用済みであること。
  - 機密情報（`DATABASE_URL` / `DATABASE_URL_POOLED` 等）は環境変数からサーバー側でのみ読み込まれ、クライアントへ露出しないこと。
  - 実行環境（OS・Node.jsバージョン・起動スクリプト／ポート・DB接続先・コミットハッシュ）は `06_test_results.md` に記録すること。
