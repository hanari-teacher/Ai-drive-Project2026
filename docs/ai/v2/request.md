# AI対話アプリ V2 要望書

## 1. 背景・目的

既存のAI質問アプリ（V1）では、単発の質問と回答を1問1答形式で記録・表示する仕組み（`ai_qa_logs` テーブル）のみを備えており、過去のやり取り文脈を引き継いだ連続的な対話や、話題ごとのスレッド管理ができなかった。

V2では、V1の既存機能およびTODOアプリに影響を与えない独立した構成（別ファイル・別ルート）で、**「文脈を維持した連続対話」「話題ごとの会話管理・切り替え」「リロード後の会話復元・再開」**を実現するAI対話アプリを構築する。

---

## 2. 要望一覧（機能要望）

| 要望ID | 要望内容 | 概要・期待する振る舞い |
| :--- | :--- | :--- |
| **WISH-V2-01** | 前のやり取りを踏まえ、同じ会話で追加質問したい。 | 同一会話内の過去の質問・回答履歴を保持し、AI（`@google/genai`）へコンテキスト（会話履歴）を含めて送信することで、文脈を踏まえた連続的な応答を得られること。 |
| **WISH-V2-02** | 話題ごとに新しい会話を作成し、一覧から切り替えたい。 | 画面上から新規会話（スレッド）を作成でき、作成した会話の一覧表示および選択による表示・対話対象の切り替えができること。 |
| **WISH-V2-03** | 再読み込み後も、保存した会話を選んで再開したい。 | 会話およびメッセージ履歴をデータベース（Neon / PostgreSQL）に永続化し、ブラウザの再読み込み（リロード）後も会話一覧から過去の会話を選択して履歴の閲覧および追加質問による再開ができること。 |

## 3. 前提条件・システム制約

既存の Express / TypeScript プロジェクトの調査結果に基づき、以下の技術スタックおよび制約を前提とする。

### 3.1 技術スタック・実行環境
* **言語 / フレームワーク:** TypeScript (`^7.0.2`), Express (`^5.3.0`), CommonJS構成
* **起動コマンド:** `npm run dev`（`tsx watch ./index.ts` / ポート `3000`）
* **AI SDK:** Google Gen AI SDK（`@google/genai` `^3.1.0`）
* **データベース:** Neon（PostgreSQL互換 / `pg` `^8.23.1`）

### 3.2 既存資産の保護・共存方針（非機能制約）
1. **V1および既存アプリとの完全分離:**
   * V1のフロントエンド（`public/ai/index.html`）、バックエンド（`src/apps/ai/`、ルート `/api/ai`）、およびTODOアプリ（`src/apps/todo/`、`src/apps/todo_v1/`、`views/todo/`、`public/todo/`）には一切変更を加えず、正常動作を維持すること。
   * V2は別ファイル・別ルートとして新規作成すること。
2. **DB接続プールの共有:**
   * `db.ts` で定義された `pool` は最大接続数が `max: 2`（`sslmode=verify-full`）に設定されているため、V2でも新規に `Pool` を生成せず既存の `pool` をインポートして共有すること。
3. **既存DBテーブルの保護:**
   * Neon上の既存テーブル `ai_qa_logs`（V1用）およびTODO用テーブルは変更・削除せず、V2用に会話管理・メッセージ履歴を保持する新規テーブル（1対多構造）を追加すること。
